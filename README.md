# Домашнее задание к работе 4

## 1. Условие задачи
Тренер формирует стартовый состав из трех игроков с номерами A, B и C. Он считает, что это "счастливая" тройка, если сумма номеров игроков делится на три без остатка. Запишите условие для "счастливой" тройки.
1. **Начало**
2. **Настроить вывод консоли на русский язык:**
   - `SetConsoleOutputCP(65001)` установить кодировку UTF-8 для корректного отображения русского текста.
3. **Объявить переменные:**
   - `A, B, C, shastchislo`.
4. **Ввести исходные данные:**
Вывести приглашение на ввод трех номеров игроков через пробел.
   - Считать значение `A, B, C` с помощью `scanf`.
5. **Вывести результаты расчетов**
   - Вывести переменную `shastchislo` с расчетом `(A + B + C) % 3 == 0`.
6. **Конец**
     
## 2. Реализация программы
```
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <windows.h> 

int schastroika(int a, int b, int c);
int main() {
    SetConsoleOutputCP(65001);
    int A, B, C;
    int result;
    printf("Введите три номера игроков (через пробел): ");
    scanf("%d %d %d", &A, &B, &C);
    result = schastroika(A, B, C);
    printf("Счастливая тройка? (1 - да, 0 - нет): %d\n", result);
    return 0;
}

int schastroika(int a, int b, int c) {
    return (a + b + c) % 3 == 0;
}
```
